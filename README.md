# ExpensesProject

Aplicativo de **gestão financeira pessoal** desenvolvido em Flutter, permitindo registrar despesas e acompanhar visualmente como os gastos estão distribuídos ao longo da semana.

## 📱 Sobre o projeto

O **ExpensesProject** foi desenvolvido para facilitar o controle de despesas do dia a dia através de uma interface simples e visual.

O usuário pode adicionar novos gastos e acompanhar a distribuição das despesas durante a semana, visualizando tanto os valores quanto a porcentagem que cada dia representa em relação ao total gasto.

## ✨ Funcionalidades

* Adicionar novas despesas
* Informar nome, valor e data da despesa
* Visualizar as despesas registradas
* Agrupar gastos por dia da semana
* Visualizar a distribuição percentual dos gastos
* Gráfico semanal de despesas
* Interface responsiva para dispositivos móveis

## 🛠️ Tecnologias

* **Flutter**
* **Dart**

## 📊 Visualização dos gastos

O aplicativo apresenta uma visão semanal dos gastos, permitindo identificar rapidamente quais dias concentraram a maior parte das despesas.

A porcentagem de cada dia é calculada com base no total gasto durante a semana.

## 🚀 Como executar

### Pré-requisitos

Antes de executar o projeto, certifique-se de ter instalado:

* Flutter SDK
* Dart SDK
* Android Studio ou outro ambiente compatível
* Um dispositivo físico ou emulador Android/iOS

### Instalação

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/expenses-project.git
```

Entre na pasta:

```bash
cd expenses-project
```

Instale as dependências:

```bash
flutter pub get
```

Execute o aplicativo:

```bash
flutter run
```
